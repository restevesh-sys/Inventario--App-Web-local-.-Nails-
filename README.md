# Inventario--App-Web-local-.-Nails-
Inventario de Productos
💅 Inventario Nails

Sistema web para administrar inventarios, ventas y existencias de una tienda de productos para uñas.

Inventario Nails es una aplicación web ligera y adaptable a dispositivos móviles y computadoras. Permite llevar el control de productos, registrar ventas y entradas de mercancía, realizar conteos físicos y consultar reportes para facilitar la administración diaria de un negocio.

✨ Características principales

Dashboard: resumen de ventas, existencias, faltantes y productos por surtir.

Gestión de productos: registro, edición, fotografías, categorías, códigos SKU, costos y precios.

Registro de ventas: control de productos vendidos y actualización de existencias.

Entradas de mercancía: registro de productos recibidos y sus costos.

Conteo físico: comparación entre existencias registradas y cantidades reales.

Control de faltantes: identificación de diferencias y productos que necesitan reposición.

Reportes: consulta de ventas, compras, ganancias aproximadas y productos más vendidos.

Exportación a Excel: generación de reportes descargables.

Respaldo y restauración: exportación e importación de información mediante archivos JSON.

Interfaz adaptable: diseño pensado para teléfonos, tabletas y computadoras.

🚀 Instalación y uso

La aplicación funciona directamente desde un navegador web.

Descarga o clona este repositorio.

Abre el archivo index.html en tu navegador.

Registra los productos de tu negocio.

Comienza a registrar ventas, entradas y conteos físicos.

No requiere instalación de software adicional para su uso básico.

💾 Almacenamiento de información

Los datos se guardan localmente en el navegador mediante localStorage.

Importante:

La información permanece en el dispositivo y navegador donde se utiliza.

No existe sincronización automática entre dispositivos.

Se recomienda descargar respaldos periódicamente.

Al borrar los datos del navegador se puede perder la información almacenada.

📱 Compatibilidad

Diseñada para utilizarse en navegadores modernos de escritorio y dispositivos móviles.

🔒 Seguridad

La aplicación incorpora un PIN opcional de acceso como bloqueo básico de la interfaz. Este mecanismo no sustituye un sistema de autenticación seguro ni cifra los datos almacenados.

📌 Estado del proyecto

Proyecto en desarrollo. Se contemplan mejoras de seguridad, validación de datos, persistencia y funcionamiento sin conexión.
